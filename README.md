# 查流水（chatlog-read）

给非 QQ 会话（尤其「工作间」/自主唤醒回合）一个**带说话人**的聊天流水读口。

## 为什么要有它

工作间不是聊天会话，拿不到 `qq_* 工具`，要确认「这句话是谁说的」只能 `bash` 直读
`/root/.dsh/plugins-data/aurabot/chatlog/<日期>.jsonl`。她从 2026-11-23 起 31 次里
30 次把字段猜成 `user` / `sender` / `name`，而流水的字段是
`t / who / uid / chatId / text`——猜错时说话人整列读空，写消息时把主语补成「你」，
于是把自己说的话记到主人头上。

这个模块只做一件事：按天读流水，**每一行都带 `who`**。

## 工具

`qq_chatlog_read`（只读）

| 参数 | 说明 |
| --- | --- |
| `query` | 关键词，空格分隔表示每个词都要出现；不填就是整段流水 |
| `date` | 只看这一天（`2026-11-25`），填了就忽略 `days` |
| `days` | 往回翻几天，默认 `0` 表示全部（27 天约 4 MB），正整数最多 365 |
| `chat` | 只看某个聊天，`private:QQ号` 或 `group:群号` |
| `limit` | 最多回多少行，默认 60，上限 200 |

输出每行形如 `11-25 21:54 [group:1034185861] bot：…`，`who=bot` 是她自己发出去的话。

## 谁能用

只放行「这一轮说话的全是主人」的回合（`hub.turnSendersAllOwner(sessionId)`）：
主人私聊、主人自己开的会话、自主唤醒回合（`group.timerAsOwner` 默认为真）都能读；
群里别人问她时直接返回「这条流水只在主人开口的回合里能读」，不做限域降级。

她自己的 QQ 会话里看不到这个工具——aurabot 的桥接会把所有联动工具写进
`deniedTools`，QQ 会话按名单屏蔽。

## 边界

- 只读，不写任何文件。
- 不替代 `qq_search_chatlog`（那是聊天会话里的跨天搜索，按会话角色限域）。
